KS CAPITAL — EXACT ORIGINAL LOGO FAVICON

This package uses the logo embedded in the supplied ORIGINAL website index.html
(img.brand-emblem), not a web-search logo, redrawn artwork or a replacement logo.
Its pixels/shape/colors are preserved; only scaled onto a transparent square canvas.

DEPLOY
1. Extract all files in this ZIP.
2. Open GitHub repository KSCapital/KS-Capital, main branch.
3. Upload files to root next to index.html, replacing index.html.
   Do not upload the enclosing folder or ZIP itself.
4. Commit changes, and Cloudflare deploys the new content.
5. Test www.kscapitaladvisory.com/favicon.png or favicon.ico.
6. Browser icon may be cached; try incognito. Google Search updates later
   when Google recrawls the website.
